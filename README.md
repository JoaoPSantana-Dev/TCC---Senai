# SISTEMA DE DISTRIBUIÇÃO DE INFORMAÇÕES POR TOTEM

<p align = "justify">O sistema de distruibuição de informações por totem é um projeto desenvolvido como TCC do curso  técnico de desenvolvimento de sistemas que tem o intuito de auxiliar na comunicação entre a administração da unidade SENAI Mariano Ferraz e seus alunos através de um totem de autoadendimento que conta com informações como horário de aulas, vagas de estágio e emprego e notícias da unidade.</p>
